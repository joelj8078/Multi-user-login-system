# Multi-user-login-system
The Multi-User Login System project is designed to provide a secure and efficient authentication mechanism for multiple users accessing a shared system. In today's digital age, ensuring the privacy and security of user data is of utmost importance. This project addresses the need for a robust login system that supports concurrent access by multiple users while incorporating strong password policies. The system employs a multi-threaded approach to handle user registration and authentication concurrently, enhancing the overall efficiency and user experience. Each user is required to register with a unique username and a strong password, meeting specific criteria to ensure security. The registration process includes checking for the existence of duplicate usernames and validating password strength.
